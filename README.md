# お礼状作成サポート

バージョン：v1.0（安定版）

特別支援学校高等部の国語「お礼状」学習用の WEB アプリです。
生徒が①〜⑧の項目をワークシート形式で埋めていくと、日本語の縦書きのお礼状（清書用便箋）が自動的に完成し、そのまま印刷できます。

## ファイル構成

| ファイル | 内容 |
| --- | --- |
| `index.html` | アプリの画面（画面1：ワークシート／画面2：清書用便箋） |
| `styles.css` | デザイン・配色・印刷用スタイル |
| `app.js` | 入力の処理、時候の挨拶・結びの挨拶のデータ、縦書きお礼状の自動生成 |
| `orei-touch-icon.PNG` | ホーム画面・タブ用のアイコン画像（`index.html`の`<head>`から参照） |
| `README.md` | このファイル |

React・Vue・データベース・サーバー・外部API・外部フォント・CDN は一切使用していません。HTML / CSS / JavaScript のみで動作する静的サイトです。

## 使い方

1. `index.html` をブラウザで開きます（GitHub Pages でそのまま公開できます）。
2. **画面1「お礼状を完成させよう」**
   - ①頭語・③お礼・⑥これから・⑧結語は最初から入力されており、変更できません。
   - ②時候の挨拶・⑦結びの挨拶は、月を選ぶと「前半」「後半」の2つの文章カードが表示されるので、当てはまる方をタップして選びます。
   - ④具体的な出来事は「実習では、」に続けて生徒が入力します。⑤心に残ったこと／学んだことは、文章のはじめから終わりまで生徒が自由に入力します（自動的に付け足される文章はありません）。
   - すべて入力できたら「作成完了」ボタンを押します。②④⑤⑦のいずれかが未入力の場合は、どこが不足しているかが日本語で表示され、清書画面には進みません。
3. **画面2「お礼状を清書しよう」**
   - 実習先の会社名（必須）、日付、学年、名前を入力します。会社名が未入力のままでは「画像で保存」「印刷する」は実行できず、押すと「実習先の会社名を入力してください。」と表示されます。会社名を入力すると、この表示は自動的に消え、通常どおり保存・印刷できます。
   - 入力に合わせて、右側の便箋プレビューに縦書きのお礼状がリアルタイムで反映されます。
   - 日付は自動で「令和八年九月十二日」のような漢数字表記に変換されます（2019年5月1日以降を令和として計算）。
   - 会社名の後ろには自動的に「御中」が付きます。
   - 便箋は縦罫線15列固定のA4便箋で、罫線は文章の量に関わらず紙面の上から下まで途切れずに表示されます。1列はおよそ25文字で右から左へ折り返しながら、本文→敬具→日付→学校名・学科学年（1つの列に連続して表示）→氏名→宛名の順に、1列ずつ続けて配置されます。
   - 敬具は最後の文章の次の列に配置され、列の下端から2マス空けた位置（下寄せ）に書かれます。日付・学校名情報・宛名は、それぞれの列の上から2マス空けた位置から書き始めます。氏名は敬具と同じく下寄せで、氏名の文字数が変わっても最後の文字が列の下端から2マス空いた位置に来るよう調整されます。
   - 敬具以降を「まとめて」次のページへ送ることはせず、1ページ目の残りの列を最後まで使い切ったうえで、本当に入りきらない分だけ自然に2ページ目へ続きます（1ページに収まる場合は不要な2枚目を作りません）。
   - 本文が15列に収まりきらない場合は、文字を縮小せずに同じレイアウトのまま自動で2枚目（必要であればそれ以上）の便箋を生成します。段落の途中でページが変わった場合は、2ページ目の冒頭で改めて一字下げをせず、文章をそのまま続けます。
   - 便箋プレビューは画面上では［2枚目］［1枚目］のように右から左の順（日本語の縦書き文書らしい並び）で表示され、開いた直後は1枚目が見える位置になっています。ただし印刷順は必ず1枚目→2枚目の順です。
   - 内容を確認したら「印刷する」ボタンでブラウザの印刷画面を開き、A4縦で印刷します（複数枚になる場合は、その枚数分のA4用紙に印刷されます）。
   - 保存の中心となるのは「画像で保存」ボタンです。Windows・Mac・iPhone・iPadのすべてで同じボタン（同じ見た目）が表示され、便箋のページだけをPNG画像として書き出します。押すと簡単な案内が表示され、「画像を保存する」を押すと保存・共有が始まります。
     - **Windows・Mac などのPC**：画像のダウンロードが自動的に始まります（複数ページの場合は1ページずつ順にダウンロードされます）。続けて画像の一覧プレビューも表示されるので、うまくダウンロードできなかった場合はそちらの「この画像を保存」からページごとに保存できます。
     - **iPhone・iPad**：端末の共有画面（共有シート）が開き、「画像を保存」または「”ファイル”に保存」を選んで保存できます。共有画面が使えない・失敗した端末では、代わりに画像のプレビューが表示されるので、画像を指で長く押すか「この画像を保存」から保存してください。
     - ページが2枚以上ある場合は、どちらの端末でも1ページずつ別々の画像として書き出されます（1枚の長い画像には連結しません）。画像は便箋の部分だけが対象で、タイトル・入力欄・ボタンなどの操作用UIは含まれません。
   - 「もどって直す」を押すと画面1に戻り、入力内容はそのセッション中は保持されます。
4. 印刷した用紙、または保存した画像を見本にして、生徒が実際の便箋に手書きで清書します。

## 個人情報・データの扱いについて

- 入力した氏名・会社名・文章などは、**ブラウザのメモリ上でのみ**扱われます。
- サーバーへの送信、外部API・AI APIとの通信、localStorage・Cookieへの保存、アクセス解析への送信は一切行いません。
- ページを再読み込みしたり閉じたりすると、入力内容はすべて消えます。

## 印刷について

- 「印刷する」ボタンは、`@media print` により、印刷時はタイトル・説明文・入力欄・ボタンなどの操作用UIをすべて非表示にし、清書用便箋だけを印刷します。
- 用紙サイズはA4縦、余白は一般的な家庭用・学校用プリンターで切れない範囲に設定しています。
- 便箋が2枚以上になる場合は、1枚ごとに改ページして印刷されます（`break-after: page`）。画面上のプレビューは縦書き文書らしく［2枚目］［1枚目］の順に見えますが、印刷順は必ず1枚目→2枚目のままです。
- 画面上でスマートフォン・タブレット向けに使っている横スクロール・行の逆順表示（`flex-direction: row-reverse`）・拡大縮小などのレイアウトは、あくまで画面表示専用で、印刷時にはすべて解除されます。
- 端末がダークモード（画面を黒基調で表示する設定）になっていても、印刷の用紙は必ず白背景・黒文字で出力されます（`color-scheme: light` を明示指定）。
- 極端に長い文章を入力すると便箋の上限枚数を超える場合があります。その際は画面上に注意メッセージを表示するので、④や⑤の文章を短くしてください。
- 以前はPC向けに「PDFで保存」（`window.print()`を使った印刷画面経由の保存）ボタンもありましたが、MacBook・iPhone・iPadではSafariの印刷・PDF化でページ数が増えたり黒背景になったりする問題があり、PC側でも保存結果が安定しなかったため、保存の主手段は下記の「画像で保存」に一本化しました。「印刷する」ボタン自体（と、その印刷レイアウト）はそのまま残っています。

## 画像で保存について（全端末共通）

- Windows・Mac・iPhone・iPadのすべてで、保存機能は「便箋のページだけを画像として保存する」方式に統一しています。PDF保存機能（PDF専用の案内・端末別のPDF案内など）は廃止しました。
- 画像化にあたって外部ライブラリ（`html2canvas` など）やCDNは使用していません。清書のレイアウトで使っている列数・1列の文字数・余白・フォントサイズなどと同じ計算式を使い、`<canvas>`に縦罫線と文字を直接描画してPNG画像を作っています。
  - 当初はDOM（完成した便箋の見た目そのもの）をSVGの`foreignObject`で複製してcanvasに描画する方式を試しましたが、`foreignObject`を含むSVG画像をcanvasに描画すると、内容に関係なくブラウザの仕様上「読み取り禁止（tainted canvas）」扱いになり、PNGとして取り出せないことが分かったため、この直接描画方式に変更しました。画面表示用の横スクロールや縮小表示の影響を受けず、常に実寸のA4サイズを基準にレンダリングするため、画面がどんな表示状態でも同じ結果になります。
  - `html2canvas` は縦書き（`writing-mode: vertical-rl`）に対応していないため、今回の用途には使用していません。
- 画像は常に白背景・黒文字で書き出されます（端末がダークモードでも影響を受けません。canvasへ描画する色を固定しているため、画面側の見た目に関わらず常に同じ結果になります）。印刷見本として使えるよう、画面の等倍よりも高い解像度（3倍）で書き出しています。
- 保存・共有の方法は端末によって異なります。
  - **iPhone・iPad**：Web Share APIで端末の共有画面を開きます。使えない・失敗した場合は画像のプレビュー画面を表示し、長押し、または画像ごとの「この画像を保存」から保存できます。
  - **Windows・Mac などのPC**：画像を自動的にダウンロードします。そのうえで画像の一覧プレビューも表示するため、自動ダウンロードがうまくいかない場合でも、ページごとに手動で保存できます。
- ページが2枚以上ある場合は、ページごとに別々のPNG画像になります（1枚の長い画像に連結することはありません）。ファイル名には日付・氏名・ページ番号を含めます（例：`お礼状_20260915_田川渉_1ページ目.png`）。
- 画像の生成や保存に失敗した場合は、分かりやすいエラーメッセージを表示します。

## 動作確認済みの環境

- スマートフォン・iPad・Windows PC の主要ブラウザ（Chrome, Edge, Safari など）
- 画面幅が狭い端末でもワークシート・便箋の入力操作ができるレスポンシブデザイン
